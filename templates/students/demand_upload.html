File format

Not sure where to start? Download the sample format — it has three example sheets (2nd/3rd/4th year installments) with the exact header rows to copy.

Every sheet in the workbook is imported, not just the first — each sheet is treated as its own installment batch (e.g. "2ND YEAR 1st Install"). A student is matched by Roll No within that installment, so re-uploading is safe: existing rows are updated in place, nothing is duplicated.

Required columns (in every sheet):

  • Roll No, Name — identify the student

Also read, if present:

ID No., Mobile Number, Email, Parent Mobile No, Admission Type, Fee Type, Group, Course, Course Fee, Section, Year, Academic Year, Issue Date, Due Date Installment 1, SDF FEE, SDC FEE, AU FEE, Exam Fee, Other Fee, Installment fee, Late fee, Re-Admission Fee, Tuition Fee (and the matching "PAST DUES - …" columns for each), Total, Remarks, RTF.
