File format

Not sure where to start? Download the sample format — it has the exact header row plus one filled-in example row to copy.

First row = column headers, matching transactions.xlsx exactly. Each row is one fee transaction; a student with several payments just has several rows sharing the same Roll No. Re-uploading is safe — rows are matched and updated by Order number, nothing is duplicated.

Required columns:

  • Order — unique transaction/order ID (rows without one are skipped)
  • Name, Roll No — identify the student

Also read, if present:

Transaction Date, Tracking, Order Status, Status Message, App Code, Amount, Merchant Amount, Currency, Billing Tel, Billing Email, Bank Name, ID No., Mobile Number, Email, Parent Mobile No, Admission Type, Fee Type, Group, Course, Course Fee, Section, Year, Academic Year, Issue Date, Due Date Installment 1, SDF FEE, SDC FEE, AU FEE, Exam Fee, Other Fee, Installment fee, Late Fee, Re-Admission Fee, Tuition Fee (and the matching "PAST DUES - …" columns for each), Total, remarks.
